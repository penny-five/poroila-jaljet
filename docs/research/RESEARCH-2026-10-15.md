# Arkistolähteiden uusintatarkistus 15.10.2026

Tässä tarkistuksessa ei löytynyt uutta palautettua oppilassivua. Alla olevat alkuperäistallenteet luettiin uudelleen. Hakujen epäonnistumista ei tulkita tallenteiden puuttumiseksi. Kokonaisia sivutekstejä, oppilasnimiä tai alkuperäisen HTML:n henkilöihin liittyviä metatietoja ei julkaista.

## Wayback: alkuperäinen HTML

HTTP 200, ilman Waybackin käyttöliittymään lisättyjä elementtejä:

- Saunalahti, 22.6.2001: https://web.archive.org/web/20010622055404id_/http://www.saunalahti.fi:80/poroila/
- DNA-etusivu, 29.6.2013: https://web.archive.org/web/20130629214829id_/http://kotisivu.dnainternet.net:80/poroila/
- DNA-kirjoitussivu, 1.7.2013: https://web.archive.org/web/20130701074848id_/http://kotisivu.dnainternet.net:80/poroila/tuntemuksiani.htm
- Kunnan koulusivukartta, 29.11.2011: https://web.archive.org/web/20111129034532id_/http://www.nummi-pusula.fi:80/koulut/sivukartta.asp?kieli=246

Saunalahden HTML:ssä kuvalinkki `olli-perustiedot.htm` toimii varsinaisena sisäänkäyntinä. Päivityslinkki on kirjoitettu muodossa `<A HREF=uudistettu.htm>` ilman lainausmerkkejä. Pelkästään lainausmerkillisiä href-arvoja etsivä poiminta jättää sen huomaamatta. Molempien kohteiden avaus samalla aikaleimalla palautti 404:n. Niiden täsmälliset CDX-haut aikakatkaistiin 12 sekunnissa. Kohdesivujen sisältöä tai säilymättömyyttä ei siten vahvisteta.

DNA-etusivun linkki on `tuntemuksiani.htm#UUSIN`: ankkuri viittaa saman HTML-tiedoston osaan, ei uuteen erilliseen sivuun.

Koulusivukartassa Hyrsylän haara käyttää parametria `sivu=121`. Esimerkiksi Linkit-osio on `default.asp?sivu=121&alasivu=245&kieli=246`. Tämä on mahdollinen tie vanhempiin koulusivuihin, mutta kohteen CDX-haku aikakatkaistiin. Koulun pääsivun kokeiltu avaus sivukartan aikaleimalla palautti 404:n. Sivukartan linkki ei ole kohdesivun sisällön tallenne eikä näyttö Poroilan tai oppilaiden tekijyydestä.

## Common Crawl: tarkistettava WARC-paikannin

Indeksi palautti yhden osuman tähän rajattuun kouluosoitteiden hakuun:

https://index.commoncrawl.org/CC-MAIN-2013-20-index?url=www.nummi-pusula.fi%2Fkoulut%2F*&output=json&filter=status%3A200&collapse=urlkey

- Alkuperäinen URL: `http://www.nummi-pusula.fi/koulut/default.asp`
- Tallennus: `20130523172235`; WARC-Date `2013-05-23T17:22:35Z`.
- WARC-Record-ID: `urn:uuid:74fe6551-89f4-42c6-9963-fae6d6014422`.
- Tiedosto: https://data.commoncrawl.org/crawl-data/CC-MAIN-2013-20/segments/1368703635016/warc/CC-MAIN-20130516112715-00009-ip-10-60-113-184.ec2.internal.warc.gz
- Pakatun tietueen offset `621155006`, length `4943`. HTTP-otsake `Range: bytes=621155006-621159948` palautti 206:n. Tämä on suuren arkistotiedoston täsmällinen tavuväli; koko tiedostoa ei tarvitse ladata.
- WARC-Payload-Digest: `sha1:V56GT3XN4YVX7B7KL3WGF2TTKZT3I47O` (arkiston ilmoittama).

Purettu tietue sisältää alkuperäisen HTTP 200 -vastauksen sekä Windows-1252-HTML:n. Otsikko on Nummi-Pusula - KOULUT. Hyrsylä mainitaan alueen viiden alakoulun joukossa. Kyse on kunnan koulujen yhteisestä sivusta, ei palautetusta oppilassivusta. WARC-tiedoston ja tietueen täsmällinen paikannin täydentää aiempaa pelkkään tutkimusajoon viittaavaa lähdeketjua.

DNA-haun `https://index.commoncrawl.org/CC-MAIN-2013-20-index?url=kotisivu.dnainternet.net%2Fporoila%2F*&output=json` vastaus oli HTTP 504. Se ei ole nollatulos.

## Arquivo.pt ja aikalaislinkki

https://arquivo.pt/textsearch?versionHistory=www.saunalahti.fi%2Fporoila%2F&maxItems=10 palautti HTTP 200, `estimated_nr_results: 0` ja tyhjän `response_items`-listan. Tulos koskee tätä osoitehakua, ei kaikkia alisivuja, osoitevariantteja tai muita arkistoja.

https://marttifi.wordpress.com/2006/04/11/poroila-is-back/ palautti HTTP 200. Alkuperäisessä HTML:ssä on suora linkki `http://kotisivu.dnainternet.net/poroila/`. Aikalaiskirjoitus tukee osoitteen käyttöä vuonna 2006; vuonna 2013 tallentuneen kohdesivun sisältöä ei voi sen perusteella ajoittaa vuoteen 2006. Blogin nykyinen HTML ei ole vuoden 2006 Wayback-tallenne.

## Julkaisuperiaate

Fiktio pysyy erikseen merkittynä. Tekijän omia väitteitä ei käsitellä riippumattomasti varmennettuina tapahtumina. Oppilaiden sivuja ei nimetä palautetuiksi ennen niiden omien tallenteiden lukemista. Tutkimus ei jatku taustalla tämän tarkistuksen jälkeen ilman erikseen asetettua automaatiota.
