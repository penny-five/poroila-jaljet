# POROILA / JÄLJET

Suomenkielinen, lähteistetty ja dokumentaarista fiktiota hyödyntävä tutkimussivusto Olli Poroilan julkisesta arkistojäljestä.

## Käynnistys

Ei riippuvuuksia eikä build-vaihetta. Avaa `index.html` selaimessa. Paikallisesti voi myös ajaa `python3 -m http.server 8000` tämän kansion sisällä.

## Julkaise GitHub Pagesiin

1. Luo GitHubiin **uusi, julkinen repository**, esim. `poroila-jaljet`.
2. Lisää tämän kansion `index.html`, `style.css`, `app.js` ja `.nojekyll` repositorion juureen.
3. Valitse **Settings → Pages → Deploy from a branch**, branch `main`, folder `/(root)` ja tallenna.
4. Sivuston URL on yleensä `https://<käyttäjä>.github.io/<repo>/`, kun GitHub vahvistaa julkaisun.

## Lähdekritiikki

Lähteet on linkitetty alkuperäisiin uutisiin, katalogeihin ja aikalaisblogeihin. Sekundäärisen blogin referoimaa vuoden 2007 oikeusuutista ei esitetä alkuperäisenä tuomiona. Presidentin kirjeaineistossa esiintyvän samannimisen henkilön ja Hyrsylän rehtorin identtisyyttä ei ole varmennettu. Fiktiiviset tekstit ovat kuvitteellisen tutkijan kirjoituksia, eivät oikeiden ihmisten ajatuksia tai puhetta.

## Hypoteesikortit ja fiktiivinen tutkija

Kolme lähdekriittistä hypoteesikorttia esittää vaihtoehtoiset selitykset ja seuraavat tarkistettavat asiakirjat. Lisäksi kolme erikseen merkittyä fiktiivistä katkelmaa on kerrottu kuvitteellisen tutkijan näkökulmasta. Kummassakaan muodossa ei keksitä tosielämän henkilöiden tekoja, motiiveja tai salattuja yhteyksiä.

## Ylläpito

Lähteet, henkilökortit, suhteet, aikajana ja pitkät raportit sijaitsevat tiedostossa `app.js`. Kaikki muokattavissa ilman ulkoisia palveluita. Verkkolähteiden pitkäaikaissäilyvyys ei ole taattu.
